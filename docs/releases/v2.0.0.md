# v2.0.0 — Local receipt manager MVP

Released 2026-10-01. Japanese receipt recognition now has a complete local workflow:
upload → detect/OCR → review → save → search → export. The 1.0 laboratory remains
available beside the new manager.

## Included

- SQLite storage of original images, raw OCR, edited values and change history.
- Merchant/date/JPY-total review, pending/reviewed status, search and CSV exports.
- Conservative editable item rows; item issues are advisory only.
- Sequential queues of up to 10 images with failed-file retry and pending bulk save.
- Duplicate-file prevention and reuse of recognition results during editing.
- Core-field quality rules and an explicitly unexecuted multimodal review plan.
- Date-only preprocessing correction, conservative parsing and one local recovery
  attempt with evidence preserved. See the [diagnostic](../date-crop-diagnostic.md).

## Validation

- 29 automated tests passed, including review/save/edit/reopen UI tests, failure
  isolation, original-data retention, audit history and CSV formula escaping.
- Full YOLO/PaddleOCR run on one original receipt, followed by save/edit/reopen and
  export in a temporary library, passed. All four field regions were detected.
- On 39 selected failed date crops, the new original-crop configuration matched
  all 39 Codex visual readings. These are not independently verified ground truth
  or overall accuracy claims. Nine prior-candidate samples were also checked.
- The management/history interface was inspected in a browser using a separate
  synthetic demo library. No real receipt data was added for the new screenshots.
- Validation used the existing macOS environment; clean installation on another
  platform has not been verified.

## Preservation and upgrade

The 1.0 application baseline is preserved at `v1.0-baseline-1135fa1` (commit
`1135fa1`). The existing `v1.0.0` model-weight release and download URL are unchanged.
Detector metrics and the original demo remain available in both READMEs.

Back up the local library while the app is stopped, update the source and restart
Streamlit. Existing records are preserved; date fixes affect new recognition and
do not overwrite historical OCR. See the [walkthrough](../manager-walkthrough.md).

## Boundaries

This is a local, single-user MVP. Actual multimodal calls, cloud sync, authentication,
full item understanding and a representative OCR accuracy benchmark are not included.
The three core fields still require user review. The next small release can add an
optional image-model adapter after provider configuration and evaluation are ready.
